# Holiday Restaurant League

Version: 1.0

---

## Purpose

A mobile-first web application for scoring restaurants during family holidays.

The application allows six participants to score each restaurant based on:

- Food
- Service
- Ambiance

Scores are stored in Google Sheets.

The website is hosted using GitHub Pages.

## Milestone 1

### Home

Displays

- Holiday Name
- Holiday Day
- Restaurant Name
- Restaurant Time
- Progress Banner
- Top 3 Leaderboard
- Submit Button

---

### Submit

Displays

- Person selection
- Food score
- Service score
- Ambiance score

One submission only.

Restaurant auto-filled.

---

### Review

Shows today's scores only.

Grouped by person.

---

### Setup

Password protected.

Allows editing of

- Holiday Name
- Holiday Day
- Restaurant
- Restaurant Time

Allows deletion of today's submissions.
